參數型別允許範圍預設說明

預設值以部署當下的 config.js 為準; 此頁與 PARAMS.md、程式內的參數白名單由 CI 自動檢查同步。

容錯規則

亂帶參數不會弄壞頁面, 規則如下(都會在瀏覽器 console 留下警告):

  • 不在表上的參數: 直接無視。
  • 非數字或超出允許範圍: 忽略該參數, 使用預設值。
  • minId > maxId 或 lookTimeMin > lookTimeMax: 自動對調。
  • boundsMin >= boundsMax: 整組退回預設 0.1 ~ 0.9。
  • count 超過可抽選的編號數量: 自動夾到 maxId - minId + 1(避免抽選卡死)。
  • ids 內的非法編號: 逐一剔除, 全部非法才退回隨機抽選。

iframe 嵌入範例

兩種嵌入對象: 上面是 widget 本體(要當疊層, 所以固定底部、點擊穿透), 下面是這份說明文件(要互動, 所以規則正好相反)。

嵌 widget 本體(網頁角落的散步隊伍) <iframe src="https://rd7-ai-gw-02.i17game.net/poke-stroll/?count=5&baseSize=120" style="position:fixed; bottom:0; left:0; width:100%; height:200px; border:none; pointer-events:none;"></iframe>

背景透明、pointer-events:none 讓點擊穿透, 不會擋到頁面上的任何按鈕; 參數直接掛在網址後面, 各專案互不影響。 想讓訪客戳寶可夢就拿掉 pointer-events:none, 但整個 iframe 矩形都會開始攔截點擊, 請自行取捨。

嵌這份說明文件(團隊 wiki / 開發者後台適用) <iframe src="https://rd7-ai-gw-02.i17game.net/poke-stroll/params.html" title="PokéStroll 參數文件" style="width:100%; height:80vh; min-height:600px; border:none;" loading="lazy"></iframe>

跟嵌 widget 相反: 文件頁要互動, 不要加 pointer-events:none; 高度給足(建議 80vh 且 ≥ 600px), 搜尋、試玩按鈕和底部預覽軌才施展得開。

postMessage 遙控

URL 參數是「載入時」的客製; postMessage 是執行中的遙控—— 父頁面隨時能隔著 iframe 疆界下指令(讓觀眾用聊天室指令召喚寶可夢, 就是靠這個)。 它是瀏覽器原生的跨視窗通道, 不走網路、不受 CORS 限制, 跨網域 iframe 直接可用。 總開關與節流見參數表的 remote / remoteRateLimit。

🕹️ 現場試玩——指令直接打進底部預覽軌
(按上面的按鈕, widget 的回執會即時顯示在這裡)

burst 要場上有色違才有效果(回執的 count 會告訴你作用到幾隻)——先按食譜「全員色違遊行」再回來玩。

快速開始(嵌入方網頁) <iframe id="poke" src="https://rd7-ai-gw-02.i17game.net/poke-stroll/" style="position:fixed; bottom:0; left:0; width:100%; height:200px; border:none; pointer-events:none;"></iframe> <script> const poke = document.getElementById('poke'); function pokeCmd(cmd, extra = {}) { poke.contentWindow.postMessage({ ns: 'poke-stroll', cmd, ...extra }, '*'); } pokeCmd('spawn', { id: 143 }); // 例: 客串一隻卡比獸高速飛過 // 回執(除錯與確認送達用) window.addEventListener('message', e => { if (e.data?.ns === 'poke-stroll' && e.data.re) console.log(e.data); }); </script>
指令參數效果
spawn id(選填, 1 ~ 1025) 客串一隻從畫面外高速橫越。帶 id 指定誰路過(不限飛行系, 遙控的卡比獸也能飛); 不帶就照常抽飛行池(含傳說機率那一層)。色違照全頁 shinyChance 擲骰
poke id(選填) 開心跳一下 + 冒愛心(跟滑鼠點擊同一種互動)。帶 id 只戳該圖鑑編號的成員, 不帶就全員
burst — 場上所有色違立刻重播星星特效(重播排程會重排, 不會越放越密); 沒有色違就是 count: 0
  • 訊息格式: { ns: 'poke-stroll', cmd: '…', …參數 }。沒帶 ns 的訊息一律無視——父頁面常有別的 iframe 在互傳訊息, 不是寄給我們的信不拆。
  • 回執: 每道指令都回 { ns, re, ok, count?, reason? } 給發送方; reason 可能是 unknown cmd / id must be 1~1025 / cameo pools not loaded / page hidden(背景分頁不生成) / rate limited。
  • 節流: 每秒最多 remoteRateLimit(預設 10)道, 超額整道丟棄——聊天室洗版也拖不垮渲染。
  • 總開關: ?remote=off 後完全靜默(連回執都不給, 像沒這功能)。
  • 刻意不驗 origin: 指令全是無害的視覺效果、無機密無狀態, 最壞情況是有人在他自己的頁面上讓皮卡丘跳舞。要鎖就直接 remote=off。
進階: 接聊天室(OBS wrapper 模式)——外部程式碰不到 postMessage, 讓 wrapper 對外連 WebSocket、對內轉譯 <!-- wrapper.html: OBS 瀏覽器來源載入這一頁(widget 本體完全不用改) --> <iframe id="poke" src="./pokemon_footer_widget.html" style="position:fixed; inset:0; width:100%; height:100%; border:none;"></iframe> <script> const poke = document.getElementById('poke'); // Twitch 允許匿名唯讀連聊天室, 零申請零金鑰 const ws = new WebSocket('wss://irc-ws.chat.twitch.tv:443'); ws.onopen = () => { ws.send('NICK justinfan12345'); // justinfan+數字 = 官方保留的匿名帳號 ws.send('JOIN #你的頻道名稱'); }; ws.onmessage = ev => { if (ev.data.startsWith('PING')) return ws.send('PONG :tmi.twitch.tv'); // 觀眾打「!pokemon 143」→ 客串一隻卡比獸 const m = ev.data.match(/PRIVMSG #\S+ :!pokemon (\d{1,4})/); if (m) poke.contentWindow.postMessage( { ns: 'poke-stroll', cmd: 'spawn', id: Number(m[1]) }, '*'); }; </script>

widget 端已內建每秒節流; 想更嚴(單一觀眾冷卻、訂閱者限定)就在 wrapper 這層做——平台相關的邏輯全關在 wrapper 裡, widget 永遠不知道 Twitch 存在。
