# 🐾 PokéStroll — 讓寶可夢在你的畫面底部散步

> 打開網頁,底下就有一排寶可夢在走來走去、蹦蹦跳跳、偶爾停下來盯著你看。
> 就這樣。沒了。但你會盯著看十分鐘。

這是一個**零依賴、零安裝、零後端**的網頁小玩具:一包靜態檔,
拖進瀏覽器就能跑,塞進 OBS 就變成直播畫面的可愛小夥伴。

---

## ✨ 牠們會做什麼?

| 行為 | 說明 |
|------|------|
| 🚶 散步 | 每隻有自己的步調,速度隨機,跳步節奏也不同步(不會像閱兵) |
| 🦘 蹦跳 | 走路時的小跳步,體型越小跳越低,起跳時影子還會縮小變淡 |
| 🧍 發呆 | 隨機停下來看向鏡頭 2~5 秒,偶爾還會**原地開心跳一下**,然後裝沒事繼續走 |
| 💬 心情對話框 | 發呆時隨機冒出**愛心/音符/黑線團/大便/Zzz/驚嘆號/問號/金色閃光**,牧場物語式的無聲交流。全部是手繪像素圖,不吃外部素材。預設冒在**面向的那一側**,尾巴從靠本體的那個下角伸出、鏡像成朝內指回本體,轉身時自動換邊,走到畫面邊緣快被裁掉也會自動翻到內側 |
| 🖱️ 滑鼠分流 | **左鍵按本體** = 抓起來拖著走、**右鍵點本體** = 戳一下、**左鍵點空白處** = 丟果實。三種按法各司其職,不用等、不會互搶 |
| 👆 戳戳互動 | **右鍵**輕點寶可夢,牠會開心跳一下 + 冒出愛心。OBS 可以用來源的「互動」視窗戳 |
| 🤏 抓起來拖著走 | **左鍵按住**寶可夢就把牠抓起來,**按下的那一刻立刻跟手**(沒有長按門檻,隨手一甩也拖得動):跟著游標走、在手上**掙扎扭動**(擺盪速度可調),放開手才自由落體回地面。抓在手上的那隻等於暫時離場——不散步、不冒對話框、不寒暄,新的果實也不會指派給牠;但**追到一半的那顆不沒收**:果實留在原地等牠,放手落地就**回去續追**——代價是落地時依「新的距離」重擲搶食的骰,被抓去遠方再放開,遠的距離就要面對遠的風險;游標拉出活動範圍時牠會**貼著邊界繼續掙扎**,不會被拖出場外 |
| 🍐 丟果實餵食 | **左鍵**點「空白處」會從點擊位置掉下一顆**像素樹果**(文柚果風的金黃小梨),距離最近且**有空**的那隻會發現它——**停下手邊的事、原地跳一下**冒出**驚嘆號**,再小跑步過來**三口吃掉 + 冒愛心**。一隻只追一顆,流程中不會發現其他果實,所以最多能同時丟**常駐數量**顆(預設 4 隻就是 4 顆)——人人有果吃,但不許搶。果實落下時**地上有影子**:越高越小越淡,快落地時放大加深,被咬小也跟著縮 |
| 🦅 空中搶食 | 果實丟得**太遠**(預設 150px 外)偶爾(預設 25%)會被盯上:被指派的那隻照常起跑,跑到**半路**一隻**飛行系**突然從畫面外進場,牠嚇得**原地停步跳一下**、再冒一次驚嘆號,賊鳥沿 **V 字軌跡**俯衝叼走果實(還在半空也接得住),再沿進場角度的**鏡像**斜上**遠走高飛**——越飛越小、越飛越淡,彷彿真的飛遠了;目擊的那隻換上**一團黑線**沮喪幾秒。果實丟在腳邊**絕對安全**——餵得近護得住,丟得遠賭一把;但**追果實的那隻被滑鼠抓走**時果實沒人護著,賊鳥會**立刻趁虛而入**——被抓著的苦主忙著掙扎,不驚嘆也不黑線,放手若還來得及落地撞見俯衝,照舊補演目擊戲。與流星客串互相獨立,兩者可同時在場 |
| ✨ 色違彩蛋 | 每一隻獨立擲骰(預設 1/100,比正作的 1/4096 慷慨得多),中獎的以**色違配色**登場,登場瞬間金色閃光對話框 + **像素星星四散特效**昭告天下,之後每 15~20 秒還會**重播一輪星星**,晚進來的人也看得到。閃光對話框有 4 秒保護期,不會被別的心情插隊蓋掉 |
| 😤 保持社交距離 | 前方太近有同伴就掉頭,不會全部黏成一坨 |
| 👋 偶遇打招呼 | 兩隻擦肩而過時,小機率**停下來寒暄**:先各退一步讓出「彼此身寬 + 一點空隙」的站位(身體不會疊在一起),面對面後才冒出音符或愛心,聊個一兩秒再轉身走開。寒暄完有冷卻,不會原地無限社交 |
| 🏷️ 名牌 | 滑鼠移到那一隻身上,頭頂浮出「**No.25 皮卡丘**」——繁體中文官方譯名,對照表隨檔案一起送、離線可用、不打 API。認得出名字才有話題;編號則是給你看的:想把牠釘進陣容就是 `?ids=25` 的那個 25。預設是 hover(OBS 與點擊穿透的 iframe 本來就沒有滑鼠碰得到,等於預設不出現);`?nametag=on` 一直掛著,**OBS 想讓名字上鏡就用這個**。色違的名字是金色的 |
| 📏 體型有考據 | 用**官方圖鑑身高**分大中小:卡比獸就是比皮卡丘大,快龍就是比迷你龍高 |
| 🎨 屬性影子 | 影子顏色跟著**主屬性**走:火系暗紅、水系暗藍、電系暗黃…低調的 18 色細節 |
| 🌅 日照影子 | 影子跟著**真實時間**走:太陽早上從畫面右邊升起、傍晚落到左邊(四分鐘 1 度),所以**早上影子往左倒、下午往右倒**,正午最短最深,越接近黃昏拖得越長越淡。夜晚只留腳下那圈**接地影**(立體感不掉);下雨下雪也不是關掉影子,是光被打散**變短變軟**。時間讀**看的人**的瀏覽器時鐘,伺服器架在哪一區都無關 |
| 🔄 撞牆回頭 | 活動範圍可設定,撞到邊界就轉身,視窗縮放也會自動適應 |
| 🏞️ 主題地面 | 腳下有**草地/水域/雪地/沙灘/岩地/土徑/熔岩**的像素地面,寶可夢會站上去(草蓋腳邊、雪會下陷、水泡到小腿),水和熔岩還會緩緩流動。**預設 `random`:每次重新整理隨機抽一種**(隨機池含「無地板」,狂按 F5 就是輪盤);`?theme=none` 完全關閉、`?theme=grass` 之類固定一種 |
| 💧 水面倒影 | 站在**水域**上時,水面下多一個上下顛倒的自己:面向跟著轉,牠往上跳、水裡的就往下沉,水紋還會左右輕輕搖。鏡面取的是**水面**而不是腳底(腳其實泡在水面下),水面那條線兩側才接得起來。能畫多高就是水有多深——預設的 6px 地面只留一抹濕痕,`?theme=water&themeHeight=40` 才看得出是倒影 |
| 🌌 夜晚演出 | 天黑之後畫面上多出三件事:上半部散開的**星空**(每顆各自閃,不齊步)、貼近地面游移的**螢火蟲**(一邊飄一邊明滅)、貼著地面往上暈開的**光暈**。**沒有月亮,也沒有整頁的夜色底**——後者是刻意的:鋪一層色溫就會蓋掉 OBS 場景與嵌入方的網頁,所以夜色全做成元素,天空維持全透明。日落**之後**才開始暗(預設 45 分鐘漸暗),日出前反向漸亮,掛整晚會自己入夜、自己天亮。想立刻看:`?sunTime=23:00`。⚠️ 代價是**星空要在偏暗的背景上才看得出來**(亮點疊在白底不會顯色);螢火蟲與地面光暈在淺底上照樣看得到 |
| 👻 夜行陣容 | 晚上偏抽**夜行系**——原作沒有這個屬性,取最接近的**幽靈 + 惡**(惡屬性和晝夜循環同在第二世代登場,出沒時段也幾乎都在天黑之後)。預設四隻裡大約三隻是這一味,偶爾混進一隻不是的,那一隻反而讓整批看起來是抽出來的。`?nightRoster=0` 關閉 |
| 🔥 主題隊伍 | `?team=fire` 就只抽火系,十八種屬性的英文名都能打,也可以逗號並列(`?team=ghost,dark`)。**主副屬性都算**——噴火龍(火/飛行)在 `team=fire` 與 `team=flying` 都抽得到 |
| 🌦️ 天氣 | 有地面就可能有天氣(預設 50%):**草地/水域/岩地/土徑下雨**(斜斜細細長長的藍色雨絲)、**雪地下雪**(白點慢慢飄、左右搖曳)、**沙灘颳風沙**、**熔岩飄火星**。風向每次隨機一邊;粒子全用 CSS 動畫循環,不吃效能。`?weatherChance=0` 永遠晴天、`?weatherDensity=2` 傾盆大雨 |
| 🌠 流星客串 | 每隔一段隨機時間擲骰,中了就有一隻**飛行系**(極低機率是**會飛的傳說**)沿隨機斜線航道、浮浮沉沉地從畫面外高速橫越,不加入常駐陣容,目擊本身就是話題。中色違的還拖著金色星塵尾跡 |
| 🎁 信使鳥空投 | 客串偶爾改派**信使鳥叼著果實**路過,半路鬆爪空投,落地後就是一般的餵食流程——最近且有空的那隻冒驚嘆號跑去吃。那一刻大家都在忙的話,果實會被**整顆叼走**不落地 |
| 📡 postMessage 遙控 | 父頁面可隔著 iframe 下指令:`spawn` 召喚客串(可指定誰,也可改派信使鳥空投)、`join` / `leave` 加入或送走常駐成員、`feed` 天降果實、`poke` 全員開心跳、`burst` 色違星星重播、`roster` 查詢目前陣容。接上你的後台或 bot,就能讓**使用者用指令召喚寶可夢**,內建節流防高頻洗版,詳見下方「遙控」一節 |

寶可夢從**第 1~5 世代(圖鑑 #1~#649)隨機抽選**,用的是黑白版的動態像素 GIF,
每次重新整理都是全新的一批 —— 抽卡的快樂,免費的。

## 🚀 怎麼玩?

> 🏠 **想先看看長什麼樣子?** 部署站有一頁[展示著陸頁 `home.html`](https://rd7-ai-gw-02.i17game.net/poke-stroll/home.html)——
> 上面那排是**真的在跑**(可以直接抓來玩),按鈕一鍵換場景:草地、雨天、夜晚、火系隊、大遊行、全員色違。
> 給還不知道這是什麼的人丟這個網址就好;要串接的人丟 `params.html`。

### 一般網頁:三秒開玩

1. 下載這個 repo(綠色 `Code` 按鈕 → `Download ZIP`,或直接 `git clone`)
2. 對 `pokemon_footer_widget.html` 點兩下
3. 沒了,你已經在玩了 🎉

> 📶 需要網路:寶可夢圖片是即時從 [PokeAPI sprites](https://github.com/PokeAPI/sprites) 抓的。

### OBS 直播疊層:當你的直播吉祥物

1. 來源 → 新增 → **瀏覽器**
2. 勾選「本機檔案」,選 `pokemon_footer_widget.html`
3. 寬高建議設成跟畫布一樣(例如 1920 × 1080),擺到圖層最上面
4. 背景本來就是透明的,直接用,不用調

改完 `config.js` 之後,在來源的屬性視窗按 **「重新整理目前頁面的快取」** 就會生效。

### 嵌入自己的網站

```html
<iframe src="pokemon_footer_widget.html"
        style="position:fixed; bottom:0; left:0; width:100%; height:200px;
               border:none; pointer-events:none; color-scheme:light;"></iframe>
```

背景透明、滑鼠點擊會穿透,不會擋到你網站上的任何按鈕。

> 🌓 `color-scheme:light` 是**透明背景的保險**:iframe 內外的配色方案不一致時,
> 瀏覽器會在 iframe 後面墊一塊不透明底(白或黑)。你的頁面若宣告過
> `color-scheme: dark`,這一句能讓內外對齊、透明照舊。

> 👆 想讓訪客也能抓、能戳寶可夢?把 `pointer-events:none` 拿掉即可 —— 但代價是**整個 iframe 矩形**
> (包含看起來透明的部分)都會開始攔截點擊,蓋在內容上方時請自行取捨。

### 📡 遙控(postMessage API)

嵌入之後,父頁面隨時能隔著 iframe 下指令——不用重新載入、不受 CORS 限制:

```js
const poke = document.getElementById('poke'); // 你的 iframe
poke.contentWindow.postMessage({ ns: 'poke-stroll', cmd: 'spawn', id: 143 }, '*');
// cmd: 'spawn' 客串一隻(id 選填;帶 delivery: true 改派信使鳥空投)
//      'poke' 開心跳(id 選填)/ 'burst' 色違星星重播
//      'join' 加一隻常駐(id 選填)/ 'leave' 送走一隻常駐(id 選填)
//      'feed' 天降果實(count 選填)/ 'roster' 查詢目前陣容(id/名字/色違/體型)
```

每道指令都有回執(`{ ns, re, ok, ... }`),內建每秒節流(`remoteRateLimit`,預設 10),
`?remote=off` 可整個關閉。完整指令表與回執欄位見 [PARAMS.md](PARAMS.md) 的
「postMessage 遙控」一節(部署站的 `params.html` 同步收錄,還有現場試玩按鈕)。

### 🔌 指令橋接(bridge.html)

postMessage 是瀏覽器內的通道,**外部程式**碰不到。同捆的 `bridge.html` 就是那道門:
對外連一個訊息來源、把收到的東西翻成遙控指令、對內丟給 widget。不用寫程式,帶網址參數就能用:

```
bridge.html?ws=wss://your-service.example/stream
bridge.html?poll=https://your-service.example/latest.json&pollInterval=3000
```

來源送 `{"cmd":"feed","count":2}`、`{"sender":"svc-a","text":"…"}` 或純文字一行都收;
文字模式只認「前綴 + 已知指令」(`!feed 2`、`!poke 25`、`!drop`…),所以整行包在別的協定裡也挑得出來,
又不會把隨便一個驚嘆號當成指令。斷線自動重連、同來源冷卻、指令白名單都內建,
參數表見 [PARAMS.md](PARAMS.md) 的「指令橋接」一節。widget 本體完全不用改。

## 🎛️ 我要調!(config.js)

所有參數都在 `config.js`,改完存檔重新整理就生效。幾個最好玩的:

> 🔗 不想改檔案?幾乎所有參數都能直接掛在**網址後面**,像 `?count=10&ids=25,133`,
> iframe 嵌入時各專案可以帶自己的參數。完整清單見 [PARAMS.md](PARAMS.md);
> 部署站還同捆互動版文件 `params.html`(可搜尋、一鍵複製、即時預覽,還有**調校台**——
> 一參數一根拉桿,調完直接複製網址)。

| 參數 | 預設 | 效果 |
|------|------|------|
| `count` | `4` | 同時幾隻。調到 20 就是寶可夢大遊行 🎪 |
| `minId` / `maxId` | `1` / `649` | 圖鑑範圍。想要「只出御三家那個年代」就設 `1~151` |
| `team` | `null` | 主題隊伍:只抽某個屬性。十八種屬性的英文名都能打,`?team=fire` 就是一隊火系 🔥 |
| `nightRoster` | `0.75` | 夜間偏抽「夜行系」(幽靈+惡)的機率。晚上大約四隻有三隻是這一味 👻,`0` = 不偏抽 |
| `baseSpeed` | `0.25` | 移動速度。調大變趕捷運,調小變老爺爺散步 |
| `bounds` | `{min:0.1, max:0.9}` | 活動範圍(占畫面寬度比例)。想讓牠們只在角落請自便 |
| `idleChance` | `0.01` | 發呆機率。調高全員站著看你,壓力有點大 |
| `bubbleChance` | `1/3` | 發呆時冒出心情對話框的機率。設 1 就是每次發呆都有話要說 |
| `idleJumpChance` | `0.003` | 發呆時原地開心跳一下的機率。調高變成跳跳樂 🦘 |
| `nametag` | `'hover'` | 名牌:`'hover'` 滑鼠移上去才出現 / `'on'` 一直掛著(**OBS 用這個**) / `'off'` 關閉 🏷️ |
| `nametagSize` | `11` | 名牌字級 px。疊在 1080p 畫面上建議放大到 14 ~ 18 |
| `bubblePosition` | `'side'` | 對話框位置:`'side'` 面向側邊 / `'top'` 頭頂 / `'none'` 關閉 |
| `bubbleLayer` | `'front'` | 對話框蓋在寶可夢身上(`'front'`)還是躲在後面(`'behind'`) |
| `bubbleSideGap` | `-5` | 側邊對話框跟身體的距離(點陣圖像素,會乘上放大倍率)。預設是負的=疊在身上,`0` 貼齊邊緣,正數則完全不重疊 |
| `bubbleSideLift` | `2` | 側邊對話框的垂直微調 px(底邊錨在身高六成處,再往上加這幾 px) |
| `shinyChance` | `1/100` | 色違機率,每隻獨立計算。調成 1 就是全員色違遊行 ✨,想回到正作手感就設 `1/4096` |
| `theme` | `'random'` | 主題地面:`'grass'` 草地 / `'water'` 水域 / `'snow'` 雪地 / `'sand'` 沙灘 / `'rock'` 岩地 / `'dirt'` 土徑 / `'lava'` 熔岩 / `'none'` 關閉 |
| `reflect` | `'on'` | 水面倒影(只在 `'water'` 出現)。水要夠深才看得出來:`?theme=water&themeHeight=40` |
| `reflectOpacity` | `0.35` | 倒影濃度。`1` 就跟本體一樣實,水面反而不像水了 |
| `reflectWave` | `1` | 水紋搖曳的倍速。`0` = 一池死水 |
| `night` | `'on'` | 夜晚演出:天黑後的星空、螢火蟲、地面光暈(沒有月亮,也沒有整頁底色——背景照樣透明) 🌌 |
| `nightStars` | `70` | 星星數量。`0` = 不要星空 |
| `nightFireflies` | `12` | 螢火蟲數量。`0` = 不要螢火蟲 |
| `nightGlow` | `0.35` | 地面光暈濃度。沒鋪地面時自動不生效 |
| `nightFade` | `45` | 日落後花幾分鐘漸暗(日出前反向漸亮)。`0` = 日落瞬間直接入夜 |
| `flybyChance` | `0.25` | 流星客串的觸發機率(每 15~20 秒擲骰一次,間隔與傳說機率也都可調) |
| `hopHeight` | `3` | 跳步高度。調到 20 會變成爆米花 🍿 |
| `baseSize` | `128` | 「大型」寶可夢的顯示高度 px,中型 = 0.8、小型 = 0.6 |
| `sunTime` | `null` | 釘死日照時刻(`'17:30'` 就是永遠黃昏)。`null` = 跟著看的人的本機時鐘 |
| `ambientShadow` | `0.55` | 夜晚剩下的接地影濃度。`0` = 夜晚完全沒有影子 |

> `maxId` 超過 649 也可以,但第五世代之後沒有動態 GIF,會自動退回靜態圖,比較沒那麼萌。

整個資料夾放在一起就好,沒有 npm、沒有 build、沒有框架——雙擊 `.html` 就能跑。
js/ 用的是傳統 `<script src>` 而非 ES modules:modules 在 `file://` 下會被 CORS 擋下,
雙擊開檔就壞了。所有檔案共用同一個全域作用域,HTML 裡的標籤順序就是依賴順序,
單元測試會照這份順序逐檔執行,順序寫錯測試直接紅燈。復古,但很自由。

> 🎨 想調影子顏色?`config.js` 的 `typeShadowColors` 一屬性一色,18 色隨你換。

## 🧪 測試

```bash
node test/widget.test.js
```

零依賴,不用 `npm install`。它照 HTML 的 `<script src>` 順序把 js/ 的每個檔案
逐一丟進同一個 Node `vm` context,配一套最小 DOM stub 跑**真正的** `Pokemon` 類別
—— 不是另外複製一份邏輯來測,所以改壞了主程式這裡就會紅燈;
載入順序寫錯(先用到後面檔案的東西)也會當場炸掉。

- **假時鐘**取代 `setTimeout`,才能斷言對話框自動收起的時序。
- **canvas stub 記錄每一次 `fillRect`**,所以對話框外框、尾巴鏡像、心情圖示是
  直接比對「畫出來的像素」,不是靠眼睛看。

需要真瀏覽器才驗得到的部分(CSS 實際套用結果、GIF 載入、視覺上好不好看)不在範圍內,
那些還是得自己開檔案看一眼。

## 🤔 常見問題

**Q: 為什麼有一隻是靜態圖不會動?**
A: 少數 ID 沒有動態 GIF,會自動退回靜態圖當備援,不會開天窗。

**Q: 為什麼用 `<script src>` 載設定,不用 `fetch()`?**
A: 因為你(和 OBS)是直接用 `file://` 開檔案的,`fetch` 讀本地檔會被 CORS 擋下來,`<script>` 標籤則暢行無阻。老派,但能動。

**Q: 切分頁回來牠們會瞬間移動嗎?**
A: 不會,有做 deltaTime 上限保護,回來時大家還在原地慢慢走。

**Q: 螢幕是 144Hz 會不會走比較快?**
A: 不會,移動速度有做時間校正,跟螢幕更新率無關。
