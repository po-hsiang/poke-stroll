# 🐾 PokéStroll — 讓寶可夢在你的畫面底部散步

> 打開網頁,底下就有一排寶可夢在走來走去、蹦蹦跳跳、偶爾停下來盯著你看。
> 就這樣。沒了。但你會盯著看十分鐘。

這是一個**零依賴、零安裝、零後端**的網頁小玩具:一個 HTML 檔 + 兩個設定檔,
拖進瀏覽器就能跑,塞進 OBS 就變成直播畫面的可愛小夥伴。

---

## ✨ 牠們會做什麼?

| 行為 | 說明 |
|------|------|
| 🚶 散步 | 每隻有自己的步調,速度隨機,跳步節奏也不同步(不會像閱兵) |
| 🦘 蹦跳 | 走路時的小跳步,體型越小跳越低,起跳時影子還會縮小變淡 |
| 🧍 發呆 | 隨機停下來看向鏡頭 2~5 秒,偶爾還會**原地開心跳一下**,然後裝沒事繼續走 |
| 💬 心情對話框 | 發呆時隨機冒出**愛心/音符/黑線團/大便/Zzz/驚嘆號/問號/金色閃光**,牧場物語式的無聲交流。全部是手繪像素圖,不吃外部素材。預設冒在**面向的那一側**,尾巴從靠本體的那個下角伸出、鏡像成朝內指回本體,轉身時自動換邊,走到畫面邊緣快被裁掉也會自動翻到內側 |
| 👆 戳戳互動 | 點一下寶可夢,牠會開心跳一下 + 冒出愛心。OBS 可以用來源的「互動」視窗戳 |
| 🍐 丟果實餵食 | 點「空白處」會從點擊位置掉下一顆**像素樹果**(文柚果風的金黃小梨),距離最近且**有空**的那隻會冒出**驚嘆號**發現它,小跑步過來**三口吃掉 + 冒愛心**。一隻只追一顆,流程中不會發現其他果實,所以最多能同時丟**常駐數量**顆(預設 4 隻就是 4 顆)——人人有果吃,但不許搶 |
| ✨ 色違彩蛋 | 每一隻獨立擲骰(預設 1/100,比正作的 1/4096 慷慨得多),中獎的以**色違配色**登場,登場瞬間金色閃光對話框 + **像素星星四散特效**昭告天下,之後每 15~20 秒還會**重播一輪星星**,晚進來的觀眾也看得到。閃光對話框有 4 秒保護期,不會被別的心情插隊蓋掉 |
| 😤 保持社交距離 | 前方太近有同伴就掉頭,不會全部黏成一坨 |
| 📏 體型有考據 | 用**官方圖鑑身高**分大中小:卡比獸就是比皮卡丘大,快龍就是比迷你龍高 |
| 🎨 屬性影子 | 影子顏色跟著**主屬性**走:火系暗紅、水系暗藍、電系暗黃…低調的 18 色細節 |
| 🔄 撞牆回頭 | 活動範圍可設定,撞到邊界就轉身,視窗縮放也會自動適應 |
| 🏞️ 主題地面 | `theme` 參數一開,腳下就有**草地/水域/雪地/沙灘/岩地/土徑/熔岩**的像素地面,寶可夢會站上去(草蓋腳邊、雪會下陷、水泡到小腿),水和熔岩還會緩緩流動 |
| 🌠 流星客串 | 每隔一段隨機時間擲骰,中了就有一隻**飛行系**(極低機率是**會飛的傳說**)沿隨機斜線航道、浮浮沉沉地從畫面外高速橫越,不加入常駐陣容,目擊本身就是話題。中色違的還拖著金色星塵尾跡 |
| 📡 postMessage 遙控 | 父頁面可隔著 iframe 下指令:`spawn` 召喚客串(可指定誰)、`poke` 全員開心跳、`burst` 色違星星重播。接上聊天室 bot 就能讓**觀眾用指令召喚寶可夢**,內建節流防洗版,詳見下方「遙控」一節 |

寶可夢從**第 1~5 世代(圖鑑 #1~#649)隨機抽選**,用的是黑白版的動態像素 GIF,
每次重新整理都是全新的一批 —— 抽卡的快樂,免費的。

## 🚀 怎麼玩?

### 一般網頁:三秒開玩

1. 下載這個 repo(綠色 `Code` 按鈕 → `Download ZIP`,或直接 `git clone`)
2. 對 `pokemon_footer_widget.html` 點兩下
3. 沒了,你已經在玩了 🎉

> 📶 需要網路:寶可夢圖片是即時從 [PokeAPI sprites](https://github.com/PokeAPI/sprites) 抓的。

### OBS 直播疊層:當你的直播吉祥物

1. 來源 → 新增 → **瀏覽器**
2. 勾選「本機檔案」,選 `pokemon_footer_widget.html`
3. 寬高建議設成跟畫布一樣(例如 1920 × 1080),擺到圖層最上面
4. 背景本來就是透明的,直接用,不用調

改完 `config.js` 之後,在來源的屬性視窗按 **「重新整理目前頁面的快取」** 就會生效。

### 嵌入自己的網站

```html
<iframe src="pokemon_footer_widget.html"
        style="position:fixed; bottom:0; left:0; width:100%; height:200px;
               border:none; pointer-events:none; color-scheme:light;"></iframe>
```

背景透明、滑鼠點擊會穿透,不會擋到你網站上的任何按鈕。

> 🌓 `color-scheme:light` 是**透明背景的保險**:iframe 內外的配色方案不一致時,
> 瀏覽器會在 iframe 後面墊一塊不透明底(白或黑)。你的頁面若宣告過
> `color-scheme: dark`,這一句能讓內外對齊、透明照舊。

> 👆 想讓訪客也能戳寶可夢?把 `pointer-events:none` 拿掉即可 —— 但代價是**整個 iframe 矩形**
> (包含看起來透明的部分)都會開始攔截點擊,蓋在內容上方時請自行取捨。

### 📡 遙控(postMessage API)

嵌入之後,父頁面隨時能隔著 iframe 下指令——不用重新載入、不受 CORS 限制:

```js
const poke = document.getElementById('poke'); // 你的 iframe
poke.contentWindow.postMessage({ ns: 'poke-stroll', cmd: 'spawn', id: 143 }, '*');
// cmd: 'spawn' 客串一隻(id 選填)/ 'poke' 開心跳(id 選填)/ 'burst' 色違星星重播
```

每道指令都有回執(`{ ns, re, ok, ... }`),內建每秒節流(`remoteRateLimit`,預設 10),
`?remote=off` 可整個關閉。完整指令表、回執欄位、以及**接 Twitch 聊天室的 OBS wrapper 範例**
見 [PARAMS.md](PARAMS.md) 的「postMessage 遙控」一節(部署站的 `params.html` 同步收錄,
還有現場試玩按鈕)。

## 🎛️ 我要調!(config.js)

所有參數都在 `config.js`,改完存檔重新整理就生效。幾個最好玩的:

> 🔗 不想改檔案?幾乎所有參數都能直接掛在**網址後面**,像 `?count=10&ids=25,133`,
> iframe 嵌入時各專案可以帶自己的參數。完整清單見 [PARAMS.md](PARAMS.md);
> 部署站還同捆互動版文件 `params.html`(可搜尋、一鍵複製、底部即時預覽)。

| 參數 | 預設 | 效果 |
|------|------|------|
| `count` | `4` | 同時幾隻。調到 20 就是寶可夢大遊行 🎪 |
| `minId` / `maxId` | `1` / `649` | 圖鑑範圍。想要「只出御三家那個年代」就設 `1~151` |
| `baseSpeed` | `0.25` | 移動速度。調大變趕捷運,調小變老爺爺散步 |
| `bounds` | `{min:0.1, max:0.9}` | 活動範圍(占畫面寬度比例)。想讓牠們只在角落請自便 |
| `idleChance` | `0.01` | 發呆機率。調高全員站著看你,壓力有點大 |
| `bubbleChance` | `1/3` | 發呆時冒出心情對話框的機率。設 1 就是每次發呆都有話要說 |
| `idleJumpChance` | `0.003` | 發呆時原地開心跳一下的機率。調高變成跳跳樂 🦘 |
| `bubblePosition` | `'side'` | 對話框位置:`'side'` 面向側邊 / `'top'` 頭頂 / `'none'` 關閉 |
| `bubbleLayer` | `'front'` | 對話框蓋在寶可夢身上(`'front'`)還是躲在後面(`'behind'`) |
| `bubbleSideGap` | `-5` | 側邊對話框跟身體的距離(點陣圖像素,會乘上放大倍率)。預設是負的=疊在身上,`0` 貼齊邊緣,正數則完全不重疊 |
| `bubbleSideLift` | `2` | 側邊對話框的垂直微調 px(底邊錨在身高六成處,再往上加這幾 px) |
| `shinyChance` | `1/100` | 色違機率,每隻獨立計算。調成 1 就是全員色違遊行 ✨,想回到正作手感就設 `1/4096` |
| `theme` | `'none'` | 主題地面:`'grass'` 草地 / `'water'` 水域 / `'snow'` 雪地 / `'sand'` 沙灘 / `'rock'` 岩地 / `'dirt'` 土徑 / `'lava'` 熔岩 |
| `flybyChance` | `0.25` | 流星客串的觸發機率(每 15~20 秒擲骰一次,間隔與傳說機率也都可調) |
| `hopHeight` | `3` | 跳步高度。調到 20 會變成爆米花 🍿 |
| `baseSize` | `128` | 「大型」寶可夢的顯示高度 px,中型 = 0.8、小型 = 0.6 |

> `maxId` 超過 649 也可以,但第五世代之後沒有動態 GIF,會自動退回靜態圖,比較沒那麼萌。

## 📁 檔案結構

```
poke-stroll/
├── pokemon_footer_widget.html  ← 主角:畫面 + 動畫邏輯,全部在這
├── config.js                   ← 你的遊樂場:所有可調參數
├── pokemon_heights.js          ← 圖鑑身高對照表(離線可用,不用打 API)
├── pokemon_types.js            ← 圖鑑主屬性對照表(影子染色用)
├── pokemon_cameo.js            ← 流星客串抽選名單(飛行系 73 隻 + 會飛的傳說 9 隻)
└── test/widget.test.js         ← 單元測試(只在開發時用,不影響執行)
```

上面五個檔案放同一個資料夾就好,沒有 npm、沒有 build、沒有框架。復古,但很自由。

> 🎨 想調影子顏色?`config.js` 的 `typeShadowColors` 一屬性一色,18 色隨你換。

## 🧪 測試

```bash
node test/widget.test.js
```

零依賴,不用 `npm install`。它把 widget 的 inline `<script>` 抽出來丟進 Node 的 `vm`,
配一套最小 DOM stub 跑**真正的** `Pokemon` 類別 —— 不是另外複製一份邏輯來測,
所以改壞了主檔這裡就會紅燈。

- **假時鐘**取代 `setTimeout`,才能斷言對話框自動收起的時序。
- **canvas stub 記錄每一次 `fillRect`**,所以對話框外框、尾巴鏡像、心情圖示是
  直接比對「畫出來的像素」,不是靠眼睛看。

需要真瀏覽器才驗得到的部分(CSS 實際套用結果、GIF 載入、視覺上好不好看)不在範圍內,
那些還是得自己開檔案看一眼。

## 🤔 常見問題

**Q: 為什麼有一隻是靜態圖不會動?**
A: 少數 ID 沒有動態 GIF,會自動退回靜態圖當備援,不會開天窗。

**Q: 為什麼用 `<script src>` 載設定,不用 `fetch()`?**
A: 因為你(和 OBS)是直接用 `file://` 開檔案的,`fetch` 讀本地檔會被 CORS 擋下來,`<script>` 標籤則暢行無阻。老派,但能動。

**Q: 切分頁回來牠們會瞬間移動嗎?**
A: 不會,有做 deltaTime 上限保護,回來時大家還在原地慢慢走。

**Q: 螢幕是 144Hz 會不會走比較快?**
A: 不會,移動速度有做時間校正,跟螢幕更新率無關。
